# YouTube Clone

Backend веб-приложения — аналог YouTube, разработанный на FastAPI. Проект поддерживает регистрацию и авторизацию пользователей, загрузку и просмотр видео, взаимодействие с контентом и модерацию.

## Функциональность

- **Авторизация:** регистрация и вход пользователей, JWT-токены, хеширование паролей.
- **Роли:** обычный пользователь (`user`), модератор (`moderator`) и администратор (`admin`).
- **Видео:** загрузка видео в S3-совместимое хранилище RustFS, проверка формата и размера файла, приватность видео.
- **Плеер:** просмотр загруженных видео с использованием временных ссылок на объекты хранилища.
- **Взаимодействие:** лайки, комментарии и подписки на каналы.
- **Модерация:** скрытие видео, обработка контента с жалобами и разграничение прав по ролям.

## Развертывание на чистой Ubuntu

Для развертывания требуется Ubuntu с доступом в интернет. Устанавливать Python, PostgreSQL, RustFS или Docker вручную не нужно: `deploy.sh` проверит Docker Engine и Docker Compose, а при необходимости установит их из официального репозитория Docker.

### 1. Клонирование репозитория

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd youtube-copy
```

### 2. Настройка `.env`

Создайте `.env` на основе `.env.example` либо отредактируйте уже созданный файл:

```bash
cp .env.example .env
nano .env
```

Укажите необходимые значения переменных окружения, в частности пароль PostgreSQL, JWT-секрет и учетные данные RustFS. Не используйте демонстрационные секреты в production-среде.

Если `.env` отсутствует, `deploy.sh` автоматически скопирует `.env.example` в `.env`. В этом случае перед production-эксплуатацией необходимо проверить и заменить значения по умолчанию.

### 3. Запуск одной командой

Из корневого каталога проекта выполните:

```bash
bash deploy.sh
```

Скрипт автоматически:

1. Проверит, что операционная система — Ubuntu.
2. Проверит наличие Docker Engine.
3. Если Docker не установлен, подключит официальный репозиторий Docker и установит Docker Engine, CLI, Buildx и Docker Compose Plugin.
4. Проверит наличие Docker Compose Plugin и установит его при необходимости.
5. Запустит и включит Docker daemon.
6. Проверит наличие `.env`; если файла нет, создаст его из `.env.example`.
7. Запустит проект командой:

   ```bash
   docker compose up --build -d
   ```

**Миграции базы данных и заполнение тестовыми данными выполняются автоматически встроенным одноразовым сервисом в `docker-compose.yml`.** Backend-сервис запускается после успешного завершения этого этапа. Отдельно выполнять `alembic upgrade head` или seed-скрипт при штатном первом развертывании не требуется.

> Скрипт не перезаписывает существующий `.env`. Если файл уже есть, его настройки сохраняются.

## Тестовые пользователи

После успешного выполнения автоматического seed-сервиса доступны следующие учетные записи:

| Роль | Email | Пароль |
|---|---|---|
| Администратор | `admin@email.com` | `admin123` |
| Модератор | `moderator@email.com` | `moderator123` |
| Пользователь 1 | `user1@email.com` | `user1111` |
| Пользователь 2 | `user2@email.com` | `user2222` |

Учетные записи предназначены для демонстрации и тестирования. Не используйте эти пароли в production-среде.

| Сервис | Адрес |
|---|---|
| FastAPI | http://localhost:8000 |
| Swagger UI | http://localhost:8000/docs |
| ReDoc | http://localhost:8000/redoc |
| RustFS S3 API | http://localhost:9000 |
| RustFS Console | http://localhost:9001 |

Для входа в RustFS Console используйте учетные данные из `.env`.

## Полезные команды

Посмотреть состояние контейнеров:

```bash
docker compose ps
```

Посмотреть логи приложения:

```bash
docker compose logs -f app
```

Посмотреть логи всех сервисов:

```bash
docker compose logs -f
```

Остановить контейнеры:

```bash
docker compose down
```

Пересобрать и запустить проект:

```bash
docker compose up --build -d
```

Остановить контейнеры и удалить данные PostgreSQL и RustFS:

```bash
docker compose down -v
```

**Внимание:** `docker compose down -v` удаляет тома с базой данных и загруженными видео. Используйте эту команду только если действительно хотите удалить сохраненные данные.
